# Silver Shop Android app — source project

This is an Android WebView app project. It is not yet a compiled APK.

## What is included
- Android app wrapper and local HTML interface
- Daily Italian silver stock in grams
- Desi silver in Tola/Masha/Ratti, converted to grams
- Purchases, sales, expenses, cash movement
- Friday OFF rows with stock carried forward
- Daily history, print/save PDF, JSON backup/restore
- GitHub Actions workflow to compile a debug APK in the cloud

## Important
- Data is stored locally on this phone. It does not sync with a laptop or other phone yet.
- This is an initial version; test calculations and keep backups before relying on it for real shop accounts.
- The APK is compiled by GitHub Actions when this project is pushed to a GitHub repository.
